# Design reference audit

This note records conceptual references for the Re:Talk official website. It is not a layout-copying brief.

## Nabla — medical confidence and contrast

- Adopt: calm clinical whitespace, alternating light and deep sections, decisive typography, and product imagery as evidence.
- Reject: enterprise claims, compliance badges, customer statistics, and AI-forward language that Re:Talk cannot substantiate.

## Apple — one scene, one message

- Adopt: each section advances one idea, with the same product surface transforming through a short sequence.
- Reject: long scroll pinning, forced scroll, heavy parallax, or desktop choreography compressed onto mobile.

## Stripe — product UI explains the system

- Adopt: use real dashboards, graphs, records, and controls as the visual explanation of structured clinical workflows.
- Reject: decorative data visualizations and fabricated dashboard states.

## Linear — typographic restraint

- Adopt: clear hierarchy, compact navigation, disciplined spacing, and quiet borders.
- Reject: dark-everywhere presentation and generic monochrome SaaS styling.

## Clay — connected section storytelling

- Adopt: transitions that make separate steps feel like one continuous system.
- Reject: playful illustration, Rube Goldberg motifs, and brand-specific visual humor that would weaken clinical trust.

## Mobile interpretation

- 390px is a primary composition, not a scaled desktop canvas.
- Use short crossfades and state changes inside one device frame; avoid long sticky intervals.
- Keep normal browser scrolling fully available, make screenshots legible, and collapse supporting copy before product imagery becomes too small.
- Reduced-motion users receive representative static product states with no content loss.

Sources reviewed: nabla.com, apple.com/iphone, stripe.com, linear.app, clay.com, and Clay's 2026 homepage process note.
